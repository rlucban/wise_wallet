## Decisions

Approved 2026-10-08: **Option A — measure first.** Options B (shared
`components/AppDialog.tsx` with our own flexbox centering container, 8 files /
17 dialogs) and C (per-dialog `translateY` nudge) were rejected at the Approve
gate. B was rejected because it is the largest possible diff against AGENTS.md
§1.11 and, if the true cause is the native modal window rather than Paper's
wrapper, it would not fix iOS at all — the same dead end as SPEC-65 Finding B.
C was rejected as a magic number that breaks on other content heights and
screens, and it violates the no-speculative-fix rule.

How each `applies` invariant is preserved by this plan:

- No code without a FINAL spec (1.1) — this plan writes no product code; the
  measured fix needs SPEC-66 marked FINAL before implement-fix starts.
- Agent runs no CLI (1.3) — every command below is handed to the user; I never
  run expo/jest/lint/tsc.
- Android + iOS + Web parity (1.5) — the three facts are captured per platform;
  if the fix ends up `Platform`-branched it must carry its own ACC row per
  platform (§1.10), and web must not regress.
- No new dependency (1.12) — rules out "replace Paper's Dialog/Modal"; the
  measured fix must use what is installed.
- Web export keeps working (1.6) — the web repro is fact 2, so a regression on
  web cannot slip through unnoticed.
- Bare-minimum diff (1.11) — the reason Option B is deferred: only choose the
  8-file migration if the facts prove it is necessary.
- Document after the change (savepoint.md) — the final slice appends to
  docs/savepoint.md and AGENTS.md §3 whatever the outcome, including
  "not reproducible".
- Ask before touching the codebase (.agents/rules/wisewallet.md) — plan only.

Layering order for whatever fix follows (follows repository.md): `components/`
(the shared dialog) → `app/` (call sites) → `utils/` (guard test). components
first so app/ only swaps imports.

Gold paths to read first: `specs/04-connection-status-vs-offline-mode.md` as the
spec template for SPEC-66 (metadata table, RFC 2119, CON-*, DEC-*, ACC-*,
D-*, Android|iOS|Web matrix split Objective vs Subjective per §1.9/§1.10);
`utils/` as the only jest `roots` entry, so any new guard test lives there.

Proof command: `npm test` (jest, roots `['<rootDir>/utils']`). Note for later:
`utils/dialogSurfaceWidth.test.ts` ACC-02 scans every `<Dialog>`/`<Modal>` in
`app/` and `components/`, so if the measured fix introduces an `AppDialog`, that
guard must be updated to accept it or the suite will fail — and must stay
meaningful, not merely relaxed.
